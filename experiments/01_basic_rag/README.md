# 01 — Basic RAG

## Goal
Build a baseline pipeline: load -> chunk -> embed -> retrieve -> generate.

## Tasks
- [ ] Load PDFs and preserve page/source metadata.
- [ ] Create a vector index and retrieve top-k chunks.
- [ ] Answer only from retrieved evidence and admit when evidence is missing.
- [ ] Add 10–20 test questions with expected source references.
- [ ] Record latency, token cost, retrieval quality, and failure cases.

## Exit criteria
A reproducible baseline exists so later techniques can be compared fairly.
